ShopCopy on the product

SEO title, meta, body HTML, and exactly 13 tags. Generated in the browser while you edit one product at admin.shopify.com.

Download shopcopy-extension.zip

What

Chrome extension that writes SEO copy for one Shopify product, on the product edit screen.

Who

Merchants editing a product in Shopify admin.

How

Unzip, Chrome → Extensions → Load unpacked → open a product → generate → copy SEO title, meta, body, 13 tags.

Install (unpacked)

  1. Download shopcopy-extension.zip and unzip it.
  2. Open Chrome and go to chrome://extensions
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select the unzipped extension folder.
  5. Open a product at admin.shopify.com → … → /products/…
  6. Use the on-page overlay or the toolbar popup. Generate, then copy. Insert body if the description editor is found.
