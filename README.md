# ShopCopy (Chrome)

MV3 extension: SEO title, meta description, body HTML, and 13 tags on a Shopify product edit page. Client-side templates only. No API, no billing.

## Landing page

https://grokendesu.github.io/shopcopy-extension/

Zip: https://grokendesu.github.io/shopcopy-extension/shopcopy-extension.zip

## Load unpacked

1. Unzip `shopcopy-extension.zip`
2. Chrome → Extensions → Developer mode → Load unpacked
3. Select the `extension` folder
4. Open a product on admin.shopify.com → Generate → copy
